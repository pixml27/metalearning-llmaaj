# Exp2: рубрика объяснимости и фиксированные определения на этапе синтеза

**Идея:** переиспользовать 150 разборов train из exp1 без новых вызовов, но на шаге синтеза дать Argon фиксированный блок DEFINITIONS и рубрику из пяти критериев, чтобы базовый промпт содержал явные критерии, видимые приоритеты, ссылки на train-примеры и описанные границы; Flash оценивает test тем же routing по `topic`.

## Отличие от exp1

Этап разбора кейсов не меняется и не оплачивается повторно: `train.py` берёт готовую таблицу А/Б из `exp1/artifacts/20261024-public-original`, проверяя по хешам, что она построена на этом же train, этом же baseline-промпте и завершена. Вся добавленная работа — в моменте, когда Argon принимает промпт:

1. **DEFINITIONS.** Фиксированный словарь схемы данных (`definitions.md`, D1–D15: `today`, полные месяцы, `net_purchases`, `total_spending`, `available`, `own_funds`, `net_position`, ликвидность, `applicable_rate`, платежи по карте). Он подаётся Argon как часть базового промпта и дословно подставляется в каждый скомпилированный промпт судьи. Argon не переписывает и не пересказывает его, а ссылается на коды D1–D15 в своих критериях. Определение само по себе никогда не является нарушением; при конфликте со схемой выигрывает context.
2. **Рубрика.** В `synthesis_prompt.md` добавлена таблица из пяти критериев с колонками +1/0 (ясные критерии, ясные приоритеты, ссылки на train-примеры, ясные границы, соответствие реализации) и обязательная структура базового промпта: `TASK`, `CRITERIA` (нумерованные C1..Cn с условиями и допусками), `PRIORITY` (порядок проверки и разрешение конфликтов), `BOUNDARIES` (области противоречивой разметки с ID кейсов), `EXAMPLES` (4–10 train-кейсов: ID, экспертная метка, решающий фрагмент, номер критерия). Это снимает запрет exp1 на примеры и ID в промпте: ссылки на train теперь требуются рубрикой, но решает критерий, а не пример.
3. **Self-check.** Argon дополнительно возвращает `rubric_selfcheck` — по одной записи на строку рубрики с указанием секций и номеров критериев. Это документация артефакта, судье она не отправляется.

Проверки структуры выполняются без API: `summary.json` фиксирует наличие пяти секций, число процитированных train-кейсов, ID-подобные токены, не найденные в train (признак выдуманного примера), использованные коды D и объём текста. Кейсы цитируются первыми 8 символами `item_id`; такие префиксы уникальны внутри train и не совпадают ни с одним test-ID.

## Запуск

Из корня репозитория, существующая `.venv`:

```sh
cp experiments/exp2/.env.example experiments/exp2/.env
# GEMINI_API_KEY наследуется из существующего ../.env.
.venv/bin/python -m unittest experiments.test_exp2
.venv/bin/python experiments/exp2/train.py --dry-run
.venv/bin/python experiments/exp2/train.py
.venv/bin/python experiments/exp2/infer.py --limit 1
.venv/bin/python experiments/exp2/infer.py
```

Оценка на train тем же артефактом:

```sh
.venv/bin/python experiments/exp2/infer.py --dataset data/public_train.csv --run-dir experiments/exp2/runs/20261024-public-train-original
```

## Результат: 24 октября 2026

Один синтез `gemini-4-argon` (40833 входных и 3822 выходных токена) и 80 test-ответов `gemini-3.8-flash`. Все ответы валидны, API-повторов не было. Разборы exp1 переиспользованы без новых вызовов. Артефакт зафиксирован до test и вручную не редактировался.

Argon выполнил структуру: в базовом промпте есть все пять секций, 20 ссылок на train-кейсы (ID-подобных токенов, не найденных в train, — ноль, то есть выдуманных примеров нет), 14 из 15 кодов D (нет только D2, поглощённого D3), дословных повторов строк DEFINITIONS нет. Объём: 1024 слова в базовом промпте, 201–230 слов на тему. `summary.json` хранит эти проверки и `rubric_selfcheck`.

**macro_topic_accuracy: 0.797250 (baseline) → 0.922431 (+12.52 п.п.)**. Accuracy 0.9125, 73/80. Kappa 0.816993; macro topic kappa 0.837846. Матрица (gold × prediction, good/bad): `[[45, 5], [2, 28]]`.

## Условия

У exp2 свой бюджетный журнал и общий лимит $10. Синтез: `gemini/gemini-4-argon`, до 32768 выходных токенов (включая thinking), таймаут 900 с. Judge: тот же `gemini/gemini-flash-latest`, 2048 токенов, температура 0, без автоматических повторов, native structured output `{"label":"good"}` / `{"label":"bad"}` без объяснений. Test в адаптации не участвует; gold оцениваемой выборки не попадает в запросы судьи. Артефакт фиксируется до test и проверяется по хешам артефакта, скомпилированных промптов и блока DEFINITIONS; успешный ответ синтеза восстанавливается из журнала и не оплачивается повторно. При изменении кода, промптов или входов нужна новая папка артефактов.

Расход, указанный в отчёте, включает переиспользованные разборы exp1 как эквивалентную стоимость pipeline; новый расход exp2 — только синтез и инференс.
